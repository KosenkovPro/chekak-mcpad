# Заметки по продукту

## Принципы

1. Vault — это обычная папка с `.md` и `.canvas` файлами.
2. Служебная папка `.mcpad/` никогда не синхронизируется.
3. Цвета, иконки и типографика живут в дизайн-токенах.
4. MCP-сервер работает read-only по умолчанию.
