# Демо-заметка

Это демонстрационный Vault для MCPad. Он лежит в обычных файлах Markdown —
никакой базы данных, всё читается любым другим редактором.

## Что здесь можно проверить

- открытие настоящего Vault вместо демо-файлов;
- атомарное сохранение: файл не остаётся наполовину записанным;
- восстановление вкладок и позиции курсора после перезапуска;
- переключение тем без перезагрузки окна.

> Попробуйте вкладку поиска: `Ctrl+F`, затем включите регулярное выражение
> кнопкой `.*` в панели поиска.
